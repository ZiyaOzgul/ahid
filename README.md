# Ankara Halkla İlişkiler Derneği (AHİD)

1990 yılında Ankara'da kurulan **Ankara Halkla İlişkiler Derneği (AHİD)**; halkla ilişkiler, kurumsal iletişim, medya ilişkileri ve kamu diplomasisi alanlarında faaliyet gösteren meslek profesyonellerini ve akademisyenleri bir araya getiren mesleki sivil toplum kuruluşudur.

Dernek; iletişim mesleğinin etik standartlarını geliştirmek, sektör ile akademi arasındaki iş birliğini güçlendirmek, mesleki gelişim programları ve yayınlarla alana katkıda bulunmak amacıyla çalışmalarını sürdürmektedir.
